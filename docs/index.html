meeting-minutes-md

Zero-dependency offline CLI, library, and Agent Skill to turn speaker-labeled transcripts (.txt, .vtt, .md) and pre-distributed agendas into editable Open Knowledge Format (OKF v0.2) Markdown meeting minutes across 7 languages (EN, DE Gesprächsprotokoll, FR Compte rendu, IT Verbale, ES Acta, PT Ata, KO 회의록).

Quick CLI Usage

npx github:onemira-space/meeting-minutes-md format call.vtt \
  --agenda agenda.md \
  --lang en \
  --title "Q4 Diligence & Architecture Sync" \
  --out minutes.md

npx github:onemira-space/meeting-minutes-md lint minutes.md --strict
